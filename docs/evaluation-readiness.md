## 评审时的操作路径

1. 登录后在首页输入链接并开始核验。链接通过短时内存交接，POST 提交，不放入应用导航 query；刷新或离开后不会自动重扫。
2. 完整报告与可用 PNG 自动保存到当前浏览器 IndexedDB。保存与分析独立，失败/缺图/敏感副本省略有明确反馈。
3. 从“查看本机快照”或首页“本机案例”回看。历史读取本机 Blob，不重新扫描、不请求过期取证端点。
4. 在个人复核区域填写理由，标记待复核，再更正或维持原判。所有个人意见只追加，模型原判始终保留。
5. 导出案例包前确认敏感内容；删除本机案例后可通过文件选择器导入，恢复原判、已保留 PNG 和复核记录。同编号拒绝覆盖。

本机记录不是云账号历史；换浏览器/设备，案例列表不会自动同步。新的评审浏览器应先运行检测或导入其自行取得的案例包。截图和复核理由可能含敏感内容，清理站点数据可能丢失记录。
